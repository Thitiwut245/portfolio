KKU Archery Club

A web application for managing the Khon Kaen University Archery Club.

Project Overview

KKU Archery Club is a web application management system for the Khon Kaen University Archery Club, designed to solve the problems of unsystematic data storage, data loss, and to facilitate club members.

The system provides a database for borrowing and returning equipment, recording scores, and tracking practice statistics so users can monitor and evaluate their own training progress. It also allows members to follow club news and updates through a central dashboard.

Technical Contributions

  • Data Management System: Organized system to prevent data loss and unsystematic storage.
  • Equipment Database: System for tracking the borrowing and returning of club equipment.
  • Performance Tracking: Allowed members to log scores and evaluate their own statistics.

KKU Archery Club Main Menu

The KKU Archery Club web application includes the following features:

  • Borrow-Return Equipment: Displays the status of equipment to facilitate borrowing.
  • Dashboard: Displays user details, equipment borrowing records, and various news/announcements.
  • Practice Score Statistics: Displays history and practice scores.
  • Record Practice Scores: Records scores from practice sessions.
