Squader

A full-stack social platform for gamers to discover and connect.

Project Overview

Squader is a platform designed to help gamers find and match with other players based on shared interests and game titles.

The application features intuitive matching mechanics and real-time communication, built as a full-stack project for the System Analysis course.

Key Features

  • Gamer Discovery: Swipe-based interaction (Like/Skip) for potential companions.
  • Mutual Matching: Real-time notifications when two players mutually match.
  • Live Chat: Socket-based instant messaging within dedicated match chat rooms.
  • Dynamic Onboarding: Multi-step registration flow for gaming preferences.

Technical Contributions

Full-Stack Development

Handled both frontend and backend implementation, ensuring seamless data flow and a responsive user experience across the entire stack.

Real-Time Architecture

Implemented Socket.IO for real-time match notifications and instant messaging, managing complex connection states and message history.

Database Management

Designed and managed the PostgreSQL schema, implementing efficient queries for discovery algorithms and match validation.
